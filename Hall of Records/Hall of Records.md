# 🏛 Hall of Records

## Character Progress

**Current XP:** 0  
**Total XP:** 0  
**Level:** 1

### XP Ledger

```dataview
TABLE tier AS "Tier", xp AS "XP", completed AS "Completed", campaign AS "Campaign"
FROM "Quest Log"
WHERE status = "Completed"
SORT completed DESC
```

### Level Rule

Every **100 XP = 1 level**.

No stats. No skill trees. No grinding for the sake of grinding.

Just evidence that you kept moving.
