# 🌱 Quest Seeds

> Raw curiosity belongs here. It does not need to become a task immediately.

## Unshaped Curiosity

```dataview
TABLE origin AS "Origin", created AS "Captured"
FROM "Quest Seeds"
WHERE file.name != "Quest Seeds"
SORT created DESC
```

### Seed → Quest

When a seed becomes actionable, create one or more quests from it and link them below the seed.

A seed may produce **one quest, several quests, or nothing at all**.
